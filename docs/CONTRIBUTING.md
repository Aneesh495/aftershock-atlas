# Contributing

Run `make test`, `make build` and `make docs` before proposing a change. Tests should target scientific invariants and independent expected values. A test that repeats the implementation is not an oracle. Synthetic known-truth inputs must be labeled synthetic and cannot satisfy real-data coverage gates.

A new metric requires a typed measurement definition, source rights, event timing, availability policy, denominator basis, missingness behavior, public disclosure rule and an actual atlas path. Add source-specific tests for corrupt data, changed definitions and duplicate populations. Do not silently extend a country's categories to another country.

Changes to preprocessing, model selection, outcome eligibility or uncertainty require a new experiment protocol version. Preserve original results. Do not optimize against frozen test failures and keep calling those observations untouched. Report simple methods winning and poor seed or interval results.

Use focused commits with the relevant checks. Do not commit raw respondent data, individual genomes, credentials, large checkpoints or private local ledgers. Keep public prose factual and tied to source identities. Scientific disagreement and missing evidence belong in findings, not hidden data cleaning.
