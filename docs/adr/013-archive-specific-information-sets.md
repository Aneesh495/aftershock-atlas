# 013: Reconstruct each origin from its designated archive

The current annual panel cannot establish historical feature availability. Official WDI editions provide a narrower useful information set, but archive months do not prove original publication days or historical territorial equivalence.

Use one designated edition per test origin and forbid current-vintage feature fallback. Allow one reference-year publication lag and explicitly predict two years from the feature endpoint. Preserve missing endpoints as exclusions. Training and calibration use only the initial edition and retained countries. Store complete row identities and arrays so a separate parser can reconstruct every feature and mask.

Index GDP separately within each edition at 2010=100 rather than asserting that the same indicator code retained a constant dollar price base. This sacrifices direct numerical score comparison with the original dollar exercise and preserves possible definition revisions. Reusing previously inspected calendar outcomes makes this exercise exploratory. A common country code remains a matching rule, not evidence of a historically stable population.

The alternative, using the final panel for missing archived cells, creates apparent coverage by injecting future information. Reject it even when models perform worse or entire test-year families disappear. The atlas displays those gaps and the verifier rejects later-edition substitution. Full temporal/geographic acceptance remains incomplete.
