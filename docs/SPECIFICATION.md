# Scientific contract

Each value has a region identity, event interval, acquisition vintage, source byte identity, metric definition, unit, frequency, and measurement kind. Acquisition time establishes a conservative availability bound. A value acquired today is never represented as historically available without archived publication evidence.

Missing values remain missing. Negative surveillance corrections remain signed. Annual estimates are never silently interpolated into weekly observations. Model uncertainty describes the fitted predictive distribution and does not establish a causal effect. A predictive no-shock trajectory is a declared extrapolation of an earlier regime.

Source-defined survey groups retain their labels, country context, instrument and mode. Host genetic summary associations remain separate from national trajectories and viral sequence submissions. No personal prediction is provided.

Release acceptance requires independently verified execution, not a green unit-test badge. Unsupported source, sampling, or identification assumptions leave their gates incomplete.
